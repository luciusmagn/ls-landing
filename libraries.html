Common Lisp libraries

A registry of packages developed by Lambda Symbolics OÜ with contributions from friends and associates. These libraries are open-source, actively maintained, and suitable for general-purpose use within their domains.

Registry

cl-colorist

luciusmagn/cl-colorist

Dependency-free ANSI text styling. Queries terminal capability and degrades cleanly on dumb terminals, pipes, and logs.

cl-exec-sandbox

luciusmagn/cl-exec-sandbox

Policy-driven sandboxing for external processes. A declared policy controls what a child may read, write, and reach; a Bubblewrap helper supplies filesystem and namespace isolation.

clifff

luciusmagn/clifff

Bindings and a supervised worker for the fff search library. The parent restarts a dead helper and resets its databases so native search cannot take down the Lisp image.

clinedi

luciusmagn/clinedi

Portable, Unicode-aware terminal line editor: grapheme-cluster movement, completion, highlighting, persistent history, and inline suggestions. Used by CCLSH and Autolith.

COLL

luciusmagn/COLL

A configurable software-license family whose operative terms are a Common Lisp association list in LICENSE.lisp; the data structure is the legal instrument, not commentary about one. Named variants such as COLL-Attribution, COLL-Copyleft, and COLL-ShareAlike name closed combinations of permissions, conditions, and limitations.

colorlisp

luciusmagn/colorlisp

Style-neutral syntax highlighting for Common Lisp applications. One native library across many languages; the host supplies colors, the library supplies spans.

lightfast

luciusmagn/lightfast

Small, direct Common Lisp bindings for FLTK 1.4, plus a deterministic flex-style layout engine for nested rows and columns. Layout calculation stays pure and separate from applying it to widgets; used by Orfeus's GUI frontend.

lispolar

luciusmagn/lispolar

A Common Lisp client for Polar.sh: checkout sessions, checkout-link URLs, customer portal sessions, and Standard Webhooks signature verification. Built to absorb Hiisi's Polar integration so application code can stay free of payment-provider glue.

ls-compat

luciusmagn/ls-compat

A portability facade for Common Lisp applications that need to run on SBCL and Clozure CL, with ECL kept loadable where practical. Deliberately narrow: it covers UTF-8 octets, timeouts, and optional POSIX and TCP primitives, leaving paths, processes, and threads to uiop and Bordeaux Threads.

mcparen

luciusmagn/mcparen

Model Context Protocol client. Speaks MCP to tool servers over stdio and HTTP with readable, inspectable protocol exchanges.

sbcl-workers

luciusmagn/sbcl-workers

Persistent, isolated SBCL worker processes and immutable heap images. Long-lived helpers that outlive individual work and can be restored from a known-good image.

sexp-store

luciusmagn/sexp-store

Crash-tolerant state files stored as readable s-expressions. Appends safely and replays after interruption; no opaque database required.
